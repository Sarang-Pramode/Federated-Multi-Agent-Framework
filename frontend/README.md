# Frontend — Federated Agent Platform Demo

Phase 1 guided visual demo. No backend, LLM credentials, or Langfuse required.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- **Next / Back** or arrow keys walk the 12-step architecture story
- **P** toggles the presenter note
- **?step=7** deep-links to a guided step
- **Live Mode** attempts to connect to `NEXT_PUBLIC_CENTRAL_URL` (Phase 2). If unavailable, Demo Mode stays available.

```bash
npm test
```
